# 클로저
- `클로저`는 함수가 종료되더라도 함수 안에 있는 변수가 사라지지 않고 계속해서 존재하며 사용할 수 있는 것을 말합니다.
- 함수의 지역 변수가 내부 함수에서 사용하고, 해당 내부 함수인 익명 함수가 원함수 보다 생명 주기가 길 경우 클로저가 됩니다.
- `클로저`는 기본적으로 `람다 함수`(`익명 함수`)와 함께 사용됩니다.
```Go
package main  
  
func Closure() func() {  
    var cnt int = 0  
  
    return func() {  
       cnt++  
       println(cnt)  
    }  
}  
  
func main() {  
    plus := Closer()  
  
    plus()  
    plus()  
    plus()  
}

// output
1
2
3
```
위 코드를 보면 `closer()`라는 함수를 익명 함수와 함께 사용한 후에 `main` 함수에서 함수를 3번 호출할 경우 변수 `cnt`의 값이 사라지지 않고 존재하여  `output`이 `1, 2, 3`으로 출력됩니다.

이렇게 함수를 호출하더라도 `i`의 값이 계속해서 유지될 수 있는 이유는 `Closure()`의 익명 함수가 `i`라는 변수를 캡쳐하고 있기 때문입니다.
